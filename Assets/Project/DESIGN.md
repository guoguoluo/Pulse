# The Very Pulse of The Machine：设计方案留档

> 版本：2026-11-04。本文记录当前的设计意图、Demo 范围和工程现状；“已实现”仅表示项目中有对应逻辑或资源，不代表最终美术、音频授权及完整体验均已验收。具体节拍调参步骤见 [Config/ConductorCalibration.md](Config/ConductorCalibration.md)。

## 一句话概念

一名独自苏醒的宇航员在异星上探索，以指挥手势唤醒环境中的光与音乐，收集日记残章，逐渐发现自己携带的是人类文明留给宇宙的最后一段回声。

## 定位和边界

- 第三人称、无死亡与惩罚性失败的音乐叙事探索游戏。玩家可以站定指挥，也可以边行走边指挥；不会自动前进。
- PC Demo 以 WASD／方向键移动、鼠标下挥指挥；镜头自动跟随，不让鼠标同时控制镜头。后续 Switch 的 Joy-Con 下挥应适配同一种 `Downstroke` 事件，首版不接入。
- 当前主场景为 `Assets/Project/Scenes/ToonStudy.unity`。第一版重点验证一段可读的“黑暗中发现节拍提示 -> 下挥点亮植物和路径 -> 解开台阶 -> 登高收集残章”体验；其余残章点位和谜题已有原型，但不视为完整关卡制作完成。
- 不做常驻节奏判定条、生命值、扣分或失败重置。节奏判断提供反馈和正向进展，不阻断玩家继续探索。

## 世界观和叙事

人类文明将走向消亡。面对“应留下什么”的问题，人们回望九种艺术形式，最终选择音乐：它可以在没有共同语言的世界里被感受。高度发达的技术将特殊频率与根系、水流、岩层等环境结合，使音乐不局限于金属设备中的一份录音，而能被异星生态重新响应。玩家是负责携带并部署储存设备的宇航员；航程没有返航余地。任务完成后，他进入休眠，醒来时失去了部分记忆。通过日记和环境回声，他推测自己可能是最后活着的人类，也终将消逝。

叙事应由探索和互动逐步揭露，而不是开局说明真相。六章日记当前按收集顺序解锁，标题分别为“选择、容器、移植、单程、休眠、回声”；正文初稿在 `Resources/TextConfig.asset` 的 `journal.01` 至 `journal.06` 条目。结尾语气既有告别，也保留音乐在另一个世界继续发生的希望。

## 核心循环

1. 在近乎全黑的场景中辨认引导流星与微弱的空间方向，探索可互动的植物、地形和日记残章。
2. 鼠标动作产生微弱的临时光；一次合格下挥产生更清楚的流星、树叶、菌丝及附近光照反馈。
3. 跟随每小节第一拍下挥，依时间偏差获得 Good、Great 或 Perfect。命中解锁后续光路；停挥后已解锁区域也会变暗，但谜题进度不倒退。
4. 到达谜题点，按该点位的节奏／空间条件积累共鸣，看到环境变化，取得残章并阅读日记。
5. 回到探索，逐步理解植物为何能够“奏乐”、旅程为何只有一人，以及自己的身份。

### 下挥与评分

`DownstrokeInput` 用鼠标相对位移估计向下速度，结合平滑、启动阈值、回落重置、最小行程和冷却抑制抖动。小幅动作独立产生 `Motion`；对准第一拍的下挥按时间误差分为 `Good / Great / Perfect`。未命中的下挥没有单独的 Off Beat 档位。当前总表默认阈值为 ±0.30 / ±0.17 / ±0.08 秒；久未进展可把 Good 辅助窗口扩大至 ±0.48 秒。原始鼠标阈值仍在 `DownstrokeInput` 组件 Inspector 中。

### 引导流星和音乐

每小节第一拍都有引导流星：拍前蓄亮，拍点按可编辑的 `GuideMeteor_Cue` / `GuideMeteor_Strike` 动画轨迹划过。流星并非常亮；它应在黑暗中足够醒目，环境变亮后融入天空，与玩家手势引发的额外视觉反馈区分。动画起止位置由动画片段决定，播放时长由调参表控制；拖尾按运动轨迹形成。

当前采用单一录音 `Assets/Project/Audio/Music/Symphony No. 7 (Mahler).mp3`，不按乐器声部拆分。`Timeline` 是节奏玩法默认模式：录音从 DSP 时间轴定时开始，以原速连续运行，流星、判定和关卡命中共用该时间轴。音量与光照共用有时效的积分：Motion / Good / Great / Perfect 分别加 5 / 10 / 20 / 50 分，默认持续 3 / 4 / 4.5 / 5 秒；各笔分数独立到期并扣除。总分可超过 100，但 100 分及以上都映射为配置的正常音量与光照；若一直不动作，总分下降，音量和光照按各自曲线柔和回落。静音时录音仍向前运行，避免拍点漂移。`GestureDriven` 是保留的试验模式，会随下挥间隔改变播放速度并在停挥后淡出、暂停；它会使固定录音拍点失准，**不能用于宣称与录音精确同步的节奏关卡**。早先讨论的“钢琴 -> 弦乐 -> 管乐”逐层加入，只是未来在取得有权使用的独立同步音轨后可重新评估的构想，非当前功能。

当前 MP3 约 1303.56 秒，`ConductorTuning.asset` 尚无经复听确认的第一拍标记；60 BPM、4 拍／小节仅为可玩的**预览节拍**，不是马勒第七交响曲整段录音的实际固定速度。不同乐章、演奏和变速不能由文件名推算。应通过 `Pulse > First Beat Marker` 按实际录音记录 Demo 使用段落的每个第一拍，检查并启用 Verified 后，才可说音乐、流星和判定完成校准。录音、提示和关卡进度在主菜单／暂停菜单中应一起停住，不发生后台漂移。正式发布前还需核实录音使用权。

## 光照与美术方向

- 三渲二风格，清透、较高明度但不过曝；外轮廓线清楚，内部结构线更淡。游戏相机的实际亮度优先于 Scene 视口观感。
- 关卡开局接近漆黑，但引导流星要可见；玩家动作后才获得环境的主要可见性。目标是“植物和菌丝在照亮世界”，而不是泛环境光把一切平均照亮。
- 光照采用有时效的累计积分：0 分全暗、100 分及以上正常光照；`Motion / Good / Great / Perfect` 默认分别加 5 / 10 / 20 / 50 分，分别维持 3 / 4 / 4.5 / 5 秒。内部总分不封顶，到期逐笔扣除；漏拍不会立即扣分。全屏遮暗、脚边灯光、植物发光和已解锁光路都随当前分数平滑升降；停挥后再次变暗，继续指挥可重新照亮。命中第一拍只永久解锁光路范围，不永久维持亮度。台阶升起、残章解谜完成等关卡状态不随积分回退。
- 天空流星、风中叶群、地表菌丝分别承担节奏提示、空间流动与路线引导。蘑菇形态以细茎宽伞为方向，未发光时保留正常材质颜色；发光时自发光和附近点光随环境反馈同步，不出现“环境亮而蘑菇全黑”。
- 宇航员、场景模型、动画和 UI 应保持同一套轮廓、材质、亮度语汇。现有程序化光路／叶片和其他场景美术属于可迭代原型，需继续以游戏相机检查过渡、层次和性能。

## 日记与谜题

`JournalArchive` 以章节数保存进度；收集点只解锁**下一章**，而不是按玩家先后发现的位置任意跳章。只要实际走近当前残章即可看到 F／拾取并收集，不再有“待共鸣”状态；节奏谜题通过地形阻隔、桥梁等空间变化控制可达性，而非禁用拾取键。跌出大地面后角色返回最后一个远离边缘的安全落脚点。J 打开独立 `JournalPage` 预制体，左右键翻页，J 或 Esc 关闭。

当前五个额外点位由 `JournalFragmentSite` 原型驱动，分别对应第二至第六章；它支持累计、连续、左右交替及按空间锚点拜访等模式。设计意图如下，具体位置、地形和视觉表现仍需关卡打磨：

| 章节 | 当前原型条件 | 期望的环境谜题表达 |
| --- | --- | --- |
| 01 选择 | 高台附近连续达到最低评级的第一拍；默认 Good 及以上连续 3 次，距离台阶 50 单位内 | 地底树藤／台阶升起后保持，登上高处取得残章；道路亮度仍随当前积分变化。 |
| 02 容器 | 近岸连续 3 次 Good 及以上 | 残章位于隔离小岛。`Journal 02 Vine Bridge` 的 `Raise` Trigger 播放 `JournalVineBridge_Raise.anim`，桥根从地下升到缺口，桥面碰撞随动画进入可走位置；已收集后重进场景直接保持终点。 |
| 03 移植 | 两侧交替命中 2 次 Good 及以上 | 两面低矮岩壁隔开一处植被温室，残章在温室内。左、右根系各回应一次后，`RootGate_Open` Animator 拉开交错的根栅，露出一人宽通道；栅栏碰撞随模型移开，不用按钮禁用拾取。 |
| 04 单程 | 顺序走访 3 个锚点，各命中一次 Great 及以上 | 高地被两道短缺口分成三个停靠点。每个锚点先唤起一段“航迹”藤板，`VoyagePath_Extend` 动画由近到远逐段接续；第一段可走后才能抵达第二锚点，最终通往残章。走错拍不清空已架设的段落，跌落回最近安全地面。 |
| 05 休眠 | 设施旁累计 4 次 Good 及以上 | 残章位于封闭的休眠舱后方，舱门与两侧岩体共同阻挡绕行。每次有效命中使藤蔓锁扣逐步松开，达到 4 次时 `HibernationDoor_Open` 播放舱门平移／上升动画；门移开后碰撞通道开放，玩家进入舱后拾取。 |
| 06 回声 | 顺序拜访 4 个回声锚点，各命中一次 Great 及以上 | 残章位于远处孤立高台。四个方向的菌丝音叉逐个共振，`EchoSpiral_Rise` Animator 依次升起环绕高台的宽阔螺旋藤路；每段成形后可站上去前往下一锚点，最后抵达顶端残章。完成后藤路不回缩，光照仍随积分衰减。 |

表中第一章由 `ConductorDemo` 与 `RisingStaircase` 控制，第 2 章已有实际地形缺口与可编辑的桥 Animator；第 3 至 6 章仍是设计方案，尚未制作地形阻隔和动画。所有路径解锁应是永久的，碰撞随可见几何一起进入可走位置；残章靠近即可拾取。各章条件在 `ConductorTuning.asset > Journal Fragment Puzzles` 配置，评分窗口与第一章共用全局配置。

## 后续验收重点

1. 为 Demo 选定具体录音段落并取得可使用的音频授权；逐小节标记第一拍，实听检查流星轨迹、声响和鼠标判定，覆盖暂停／继续与不同帧率。
2. 玩家不读长说明也能发现“动作点亮环境”和“跟随流星命中可解锁更多光路”；停止指挥后已解锁区域变暗，在不挥动时仍能找到流星与基本方向。
3. WASD 与下挥同时可用；微小鼠标动作不造成刺眼闪光；积分增加后的全屏遮暗、脚边光和菌丝发光同步平滑过渡，且没有明显方格边界。
4. 第一章满足连续命中条件后确实触发 `Raise`、看到台阶上升并能走上高处；积分归零只影响光和音量，不让台阶缩回、不撤销解谜进度。再逐个验收其余五个点位的空间条件、反馈、拾取和章节顺序。
5. 全流程检查主菜单、新游戏／继续、暂停、教学、日记分页、中文字体覆盖和存档恢复；将仍散落在其他脚本的判定与光照参数逐步收束，避免多个来源相互矛盾。
